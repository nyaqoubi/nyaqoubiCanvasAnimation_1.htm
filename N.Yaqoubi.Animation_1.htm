Example / Assignment Animation #1

The HTML5 <canvas> element lets us draw shapes and animate them with JavaScript. By drawing, clearing, and redrawing objects with slightly different positions on each frame (using requestAnimationFrame()), we create motion.

Below is a live canvas demo. For grading:

  • Object Color: Primary circle color changed to a teal-blue.
  • Object Size: Primary circle radius set to 40 (bigger than default).
  • Canvas Location: Canvas moved to the right column of the page layout.
  • Movement Direction: Diagonal for the circle; vertical for the square.
  • Second Object: Added a square that moves vertically.
